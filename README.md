# Meliora

## Overview

Meliora is a private project with a frontend built using React and a backend built using Express. Both the frontend and backend are deployed separately on Vercel.

## Project Structure

- **frontend/**: Contains the React application.
- **backend/**: Contains the Express application.

## Deployment

Both the frontend and backend are deployed on Vercel using the `main` branch. Any changes to the codebase should follow the branching strategy outlined below to ensure smooth deployment.

## Branching Strategy

1. **Create a new branch**: For any changes or new features, create a separate branch from `main`.
2. **Work on the new branch**: Make your changes and commit them to the new branch.
3. **Merge to main**: Once the changes are complete and tested, merge the branch back into `main`.

**Note**: Each commit to the `main` branch will trigger a deployment on Vercel.
